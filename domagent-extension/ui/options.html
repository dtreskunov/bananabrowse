    What sharing means

    Your assistant uses a separate tab, never an existing tab you are using. It shares your website sign-ins and can read private information on the page. Website access is requested only when you choose Share a tab.

    Page scripts, if you choose to allow them, can read page information and make network or account changes. Pictures and page text may contain private information.

    Stop sharing stops new actions, not requests or scripts that already started. The tab stays open so you can inspect it. Finish sensitive sign-ins yourself, then approve a new sharing request.

    The banner is a helpful reminder, not a guarantee: websites can hide or imitate it. Check the extension toolbar too. A lost connection or browser restart stops all sharing.
