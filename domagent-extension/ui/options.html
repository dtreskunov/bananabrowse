    What sharing means

    You select an existing or new website tab using the toolbar. Only that tab is shared; your browser profile is not an API. Shared tabs use your website sign-ins and can reveal private information.

    Actions, including page scripts, need your approval. Allow all while sharing applies only to ordinary actions in that tab until sharing ends. Page scripts can make network or account changes.

    You can navigate, sign in and interact normally. Human assistance asks for Done or Cancel and does not end sharing. Stop sharing stops new actions, not scripts or requests already started, and leaves your tab open.

    The banner can be hidden or imitated, but its approval handler requires a real user gesture. Check the trusted extension toolbar, popup or settings as a fallback. A lost connection or browser restart stops all sharing.
