    Before granting page control

    Each approved client gets an extension-created dedicated tab, never your existing active tab. HTTP(S) page access, including intranet sites, requires broad optional host permissions, requested when you approve. The service permission is requested when you save its origin.

    This is not a separate browser profile or network sandbox. Tabs share your website logins. Page JavaScript can read page-visible secrets, non-HttpOnly cookies, local/session storage, and use ordinary page APIs to make network/account changes. Screenshots and text may contain secrets.

    Pause stops new commands only. It cannot undo prior requests, side effects, or already scheduled JavaScript. Tabs stay open for inspection. Password/CAPTCHA detection is conservative, not a guarantee. Finish sensitive flows yourself, then request and confirm a fresh approval.

    No raw CDP, browser profile/files, cookie export, download UI, permission UI, or current-tab adoption is exposed. Firefox page evaluation can be unavailable under a page CSP; screenshots use only the explicitly approved tab.
